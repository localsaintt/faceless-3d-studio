# Owner preferences

What the owner has asked for or decided. Claude follows these in every session.

- **Approval gates:** never buy, subscribe, create accounts, use paid APIs, publish or post. The owner approves scripts (`script-approved`) and finished videos (`approved`) in Obsidian.
- **Obsidian is the control room:** scripts, storyboards, renders and QC appear in the video note; the owner's own notes go under "Your notes".
- **Quality:** native 1080×1920 by default. In the A/B the owner saw no noticeable difference with 720p-upscaled, so `final_720` is fine on busy days.
- **Storage is a concern** (MacBook Air, ~29 GB free). Delete render frames automatically, archive approved videos to iCloud, warn before the disk gets low.
- **Mac comfort:** renders run with `caffeinate`, the lid stays open and the Mac stays plugged in. Heavy apps (and the Blender app) are closed during renders.
- **Wants speed over time:** reuse kits, recipes and lessons so later videos are fast; read Studio Memory before every new video.
